# AIConversationManager — 機能仕様書

## プロジェクトの目標

ローカルで動作するAIチャット履歴管理ソフトウェア。複数のAIプラットフォームに分散している会話をエクスポートしてデータベースに集中的に保存し、専用に設計されたインターフェースでこれらの記録を閲覧・管理できるようにする——特に長大な会話の中で重要でない部分を非表示にして、本当に価値のあるコンテンツだけを残せるようにすること。

## データソース

- ブラウザ拡張機能のようなリアルタイムクロールは行わず、各AIプラットフォーム**標準のエクスポート機能**を使用して、ユーザーが公式にエクスポートしたZIPファイルをダウンロード
- ソフトウェアのアップロードページでこのZIPを送信すると、プログラムが解析してデータベースに書き込む
- 繰り返しのアップロードをサポート：新しいZIP/JSONをアップロードするたびに、会話ごとに增量同期する
    - upsert操作を使用して重複したレコードの作成を回避
    - ユーザーが手動で設定した`hidden`状態は再インポート時に保持され、上書きされない
    - 会話のタイトルとメッセージの内容のみを更新し、ユーザーの管理状態を維持

## 対応プラットフォーム

- ChatGPT
- Gemini
- Claude
- DeepSeek

各プラットフォームのエクスポート形式は異なるため、それぞれ独立したParserで処理し、プログラム内部で共通のConversation / Messageデータ構造に統一してからデータベースに保存する。

## コア機能

1. **インポート**：ZIPをアップロード → プラットフォームに応じて対応するParserで解析 → データベースに書き込み（增量）
2. **閲覧**：左側のサイドバーに会話リストを表示し、右側のメインエリアに選択された会話の完全な内容を表示
3. **管理**：ユーザーは会話内の不要な部分（無駄な雑談など）を自由に非表示にでき、非表示状態は永続的に保存されて次回の起動時も保持される

## インターフェース構成

- ログインページ（現段階では実際のアカウントシステムはなく、クリックすると直接ホームページに遷移）
- MyPage（ホームページ）：左側の会話リスト + 右側のコンテンツ表示エリア、左側のサイドバー上部に「アップロードページ」へのリンクがある
- アップロードページ：ZIPファイルを選択して送信

## 技術アーキテクチャ

- **フロントエンド**：React + TypeScript + Vite + marked（Markdown解析） + DOMPurify（XSS保護）
- **バックエンド**：NestJS + Prisma ORM v7
- **データベース**：SQLite（ローカルファイル型データベース、別途データベースサービスをインストールする必要がない）
- **データベースモデル**：
  - `Conversation`テーブル：会話の基本情報を保存、`hidden`フィールドで非表示かどうかをマーク
  - `Message`テーブル：メッセージの内容を保存、同様に`hidden`フィールドでメッセージレベルの非表示をサポート
- **バックエンドモジュール構成**：
  - `conversation`モジュール —— 4つのプラットフォーム専用Parser（chatgpt / gemini / claude / deepseek）を内包、統一されたインターフェースでマルチプラットフォームの解析を拡張可能
  - `prisma`モジュール —— データベースサービスをカプセル化
  - `user`モジュール —— 開発は暂缓、現在はアカウントシステムなし
- **フロントエンドの主要な特性**：
  - 会話詳細のキャッシュメカニズムで重複したリクエストを回避
  - 楽観的UI更新でインタラクションの体験を向上（操作失敗時は自動的にロールバック）
  - 完全なフィルタリング機能：プラットフォームフィルター、日付範囲フィルター、非表示コンテンツのフィルター
